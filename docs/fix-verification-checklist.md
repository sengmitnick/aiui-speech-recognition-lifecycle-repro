# 官方修复后的真机验证清单

本清单用于比较修复前后版本。每项都应记录源码提交、设备、系统 Build、AIUI Runtime 和公开证据编号。

## 基础生命周期

- [ ] 单次识别基线连续 10 次均返回文本或明确错误，并收到终态。
- [ ] 自动续听连续完成至少 20 次 `start -> result/error -> onend -> start`，没有无结果、无错误、无结束的分段。
- [ ] 每个接受的 `start()` 都能关联到唯一、可解释的终态。

## 自然停顿

- [ ] 用户说前半句，静默 2 至 3 秒后继续说，后半句可进入后续分段并返回。
- [ ] 用户静默 5 秒后继续说，运行时仍返回文本或明确错误，不永久假活。
- [ ] 云端返回变慢时，应用不需要用固定超时猜测性地中止会话。

## 中止与页面生命周期

- [ ] 用户主动停止后，麦克风和事件 target 能可靠释放。
- [ ] `abort()` 后立即开始新一轮，不会收到旧会话的晚到回调。
- [ ] 页面切换、退出再进入、连续新建轮次后仍可正常识别。
- [ ] 页面销毁后没有旧会话继续占用麦克风或向新页面派发事件。

## 对照与回归

- [ ] 同一设备、同一源码在修复前版本能够复现或出现疑似证据。
- [ ] 修复版本按相同固定语句、停顿、轮数和日志工具执行。
- [ ] 至少进行三次独立冷启动测试，而不是只在一次会话中循环。
- [ ] 公开修复证据经过脱敏和人工逐行复核。
- [ ] 项目状态只有在上述证据通过后才改为“已验证修复”。
